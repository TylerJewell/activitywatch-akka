## What was copied

### The web interface, in full

`webui/` is ActivityWatch's own `aw-server/aw-webui`, vendored unchanged, and
`src/main/resources/static-resources/` is what `npm run build` produces from it. This is
deliberate: `RENDERING.md` R3 says a port that has an interface reuses the original's rather
than rebuilding it, so that what a user sees is the original's work and the port is measured
by how little of it had to change.

Three files differ, and nothing else does:

| File | Change |
|---|---|
| `src/stores/stream.ts` | new — subscribes to the port's event stream |
| `src/stores/buckets.ts` | +7 lines — takes an update from the stream instead of re-polling |
| `src/views/Alerts.vue` | +9 / −2 lines — same |

The diff is confined to the data layer; no view, no route, no stylesheet and no asset was
touched. `activitywatch-port/gui/manifest.json` records the comparison against screenshots
captured from the original.

### The queries a client sends

`src/main/java/io/akka/activitywatch/domain/Queries.java` reproduces the `query2` text that
`aw-client/aw_client/queries.py` builds — to the byte, including the blank lines its `join`
leaves behind and the ten-space indentation inside the browser section. A query string is not
an implementation detail here: a caller sends the same text to either system and compares the
two answers, so a query that was reworded would be a different question.

### The default categories

`src/main/java/io/akka/activitywatch/domain/DefaultClasses.java` carries the thirteen
category rules and their regular expressions from `aw-client/aw_client/classes.py`, including
which three are case-insensitive and which ten are not. An event only lands in the same
category on both systems if the patterns are the same patterns.

### The study build's privacy filter

`src/main/java/io/akka/activitywatch/domain/ResearchFilter.java` carries the list of browser
application names from `aw-watcher-window`, which decides whether a window keeps its
application name when its title is stripped.

### The literal strings the API is made of

Route paths, JSON keys, query-language function and token names, configuration keys,
directory names, and the exact text of the errors the original answers with —
`KeyError: '<key>'`, `Extra data: line 1 column 5 (char 4)`, `Nothing to assign`, and the
rest. `python toolkit/copied_strings.py activitywatch` finds 264 literals of ten characters
or more that occur in both projects; every one is in that set, in
`ApiEndpoint.java`, `Guards.java`, `QueryFunctions.java`, `QueryToken.java`,
`QueryParser.java`, `ActivityWatchClient.java`, `AwClientCli.java`, `Dirs.java` and the tests
that compare them against the original's answers. They are the contract, not prose: a caller
branches on the `type` field of a 400, so a reworded message is a changed API.

### The licence text

`LICENSE`, verbatim.

## What was not copied

**No Python or Go source file was copied, in whole or in part.** Every rule this port
implements was established by running the original and written down in
`activitywatch-port/specs/SPEC-001-activitywatch.md`, with the run that established it
recorded in `activitywatch-port/docs/question-log.md`.

`activitywatch-port/probes/corpus.json` — the 260 expected answers the port's tests are
checked against — was **generated by running** the original, not copied from its test suite.
It holds outputs, not code. No fixture, schema or test file was copied either.

## What is derived

The behaviour, and deliberately so. This is a port: the rules for merging a heartbeat into
the event before it, for deciding when a machine counts as untouched, for what a range query
selects and clips, and for turning recorded windows into time per application are
ActivityWatch's rules. Everywhere this port answers differently the difference is listed in
`README.md` under "Where it differs from ActivityWatch/activitywatch", and each has an entry
in SPEC-001 §4.

Names carried over from the original, because a port that renames what it copies is harder to
check against it: `bucket`, `heartbeat`, `pulsetime`, `afk` and `not-afk`, `flood`,
`query_bucket`, `find_bucket`.
