This project is a port of **[ActivityWatch/activitywatch](https://github.com/ActivityWatch/activitywatch)**.

## What licence the original is under

Mozilla Public License 2.0, on all four packages this port was built against —

ActivityWatch contributors, principally Erik Bjäreholt and Johan Bjäreholt. Read each
project's own `LICENSE.txt`; the figure above came from those files, not from a badge.

## What was copied

**No source file was copied, in whole or in part.** No prompt, fixture, schema or test
corpus was copied either. The one file taken verbatim is the licence text itself, which
appears here as `LICENSE`.

`bench/corpus.json` in the harness repository — the expected answers this port's tests are
checked against — was **generated by running** the original, not copied from it. It holds
outputs, not code.

## What is derived

The behaviour, and deliberately so. This is a port: the rules for merging a heartbeat into
the event before it, for deciding when a machine counts as untouched, and for turning
recorded windows into time per application are ActivityWatch's rules, established by
running ActivityWatch and written down in `specs/SPEC-001-activitywatch.md` in the harness
repository. Everywhere this port answers differently, the difference is listed in
`README.md` under "Where it differs from ActivityWatch/activitywatch".

Names carried over from the original, because a port that renames what it copies is harder
to check against it: `bucket`, `heartbeat`, `pulsetime`, `afk` and `not-afk`, `flood`.
